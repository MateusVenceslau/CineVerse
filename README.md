# 🎬 CineVerse

Aplicativo mobile de filmes desenvolvido com React Native e Expo, integrado à API do TMDB para consulta de filmes, exibição de detalhes e organização de catálogo.

## 📱 Sobre o projeto

O CineVerse é um aplicativo que permite explorar filmes, consultar informações e visualizar detalhes de cada título, integrando tecnologias de frontend, backend e banco de dados.

## ✨ Funcionalidades

- Catálogo de filmes.
- Busca e consulta de filmes.
- Visualização de detalhes dos filmes.
- Integração com API REST do TMDB.
- Backend próprio para gerenciamento de dados.
- Conexão com banco de dados TiDB Cloud.
- Integração com Google Cast para transmissão para TV.

## 🛠️ Tecnologias utilizadas

**Frontend**
- JavaScript
- React Native
- Expo

**Backend**
- Node.js
- Express

**Banco de dados**
- TiDB Cloud

**Integrações**
- API TMDB
- Google Cast

**Hospedagem**
- Render

## 🏗️ Arquitetura

O projeto utiliza uma arquitetura com frontend mobile e backend independente.

O aplicativo realiza requisições HTTP ao backend, que gerencia as operações e integrações necessárias com os serviços externos e o banco de dados.

## 🚀 Objetivo

Desenvolver uma aplicação mobile completa, colocando em prática conhecimentos de desenvolvimento de interfaces, consumo de APIs REST, construção de backend, integração com banco de dados e serviços externos.
